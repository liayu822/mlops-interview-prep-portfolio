# Resume Bullet Drafts

Use this file to convert project work into concise, resume-ready bullets.

## Formula

Strong resume bullets usually include:

- Action verb
- Technical task
- Tool or method
- Result or impact

Example format:

```text
Built a FastAPI-based ML inference service for manufacturing quality prediction, including input validation, prediction logging, and automated tests.
```
