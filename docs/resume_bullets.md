# 履歷 Bullet Drafts

這個文件用來把專案進度轉換成簡潔、適合履歷使用的 bullets。

## 寫法公式

好的 resume bullet 通常包含：

- Action verb
- 技術任務
- 使用的工具或方法
- 結果或影響

範例格式：

```text
Built a FastAPI-based ML inference service for manufacturing quality prediction, including input validation, prediction logging, and automated tests.
```
