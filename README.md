# AI/ML Engineer Interview Preparation Portfolio

This repository documents my structured preparation for entry-level AI/ML Engineer, AI Application Engineer, MLOps, and IT automation roles.

I use this portfolio to record my learning process, coding practice, project development history, interview notes, and resume-ready project summaries. The goal is not only to finish exercises, but also to build evidence of consistent technical growth and practical engineering judgment.

## Target Roles

- AI/ML Engineer
- AI Application Engineer
- Entry-level MLOps Engineer
- IT Automation Engineer
- Data or ML-focused Software Engineer

## Repository Purpose

This repository tracks five areas of preparation:

1. Weekly learning progress and reflection
2. LeetCode and SQL practice
3. An end-to-end ML production pipeline project
4. Interview notes for core technical topics
5. Resume-ready summaries and project stories

The structure is designed to make progress visible over time. Each folder should help answer a future interview question such as: What did I learn, what did I build, what problems did I solve, and how did I improve?

## 8-Week Learning Roadmap

| Week | Focus | Main Outcome |
| --- | --- | --- |
| Week 1 | Python, Git, project structure | Set up the portfolio, review Python fundamentals, and practice Git workflow |
| Week 2 | SQL, ETL, data ingestion | Practice SQL queries and design a basic data ingestion flow |
| Week 3 | ML baseline and evaluation | Train a baseline model and define evaluation metrics |
| Week 4 | Feature engineering and error analysis | Improve features and analyze model mistakes |
| Week 5 | FastAPI inference service | Build an API endpoint for model prediction |
| Week 6 | Docker, pytest, and GitHub Actions | Add tests, containerization, and CI workflow |
| Week 7 | Model lifecycle, logging, and monitoring | Add prediction logging and model lifecycle documentation |
| Week 8 | Resume packaging and mock interview review | Convert project work into resume bullets and interview stories |

## Weekly Deliverables

Each week should produce:

- One weekly learning log
- Several LeetCode or SQL practice records
- Measurable progress on the ML production project
- Notes on interview-relevant concepts
- A short reflection on bugs, gaps, and next steps

Weekly logs are stored in `weekly_logs/`.

## Tracking LeetCode and SQL Practice

LeetCode and SQL work is organized by topic:

- `leetcode/arrays_hashmap/`

- `leetcode/binary_search/`
- `leetcode/stack_queue/`
- `leetcode/tree_graph/`
- `leetcode/dynamic_programming/`
- `leetcode/sql/`

For each problem, I should track:

- Problem name and link
- Pattern or topic
- Initial approach
- Final solution idea
- Time and space complexity
- Mistakes made

The template is available in `leetcode/problem_template.md`.
